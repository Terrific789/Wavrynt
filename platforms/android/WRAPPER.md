# Gradle Wrapper provenance

The shared Android template uses Android Gradle Plugin 8.9.2 and Gradle 8.11.1. This matches the [AGP 8.9 compatibility table](https://developer.android.com/build/releases/agp-8-9-0-release-notes). No global Gradle installation is required to build an application.

The Wrapper scripts and JAR were generated by the official Gradle 8.11.1 distribution's `wrapper` task, in an isolated empty project. The distribution was downloaded from:

- https://services.gradle.org/distributions/gradle-8.11.1-bin.zip
- Its published checksum: https://services.gradle.org/distributions/gradle-8.11.1-bin.zip.sha256

The downloaded archive's SHA-256 was checked before extraction and execution:

```text
f397b287023acdba1e9f6fc5ea72d22dd63669d59ed4a289a29b1a76eee151c6
```

The generation command, using that verified distribution, was:

```powershell
gradle.bat -p <empty-bootstrap-project> --offline --no-daemon --console=plain wrapper --gradle-version 8.11.1 --distribution-type bin --gradle-distribution-sha256-sum f397b287023acdba1e9f6fc5ea72d22dd63669d59ed4a289a29b1a76eee151c6 --no-validate-url
```

The generation task completed successfully. `--no-validate-url` avoided a redundant online HEAD request during offline generation after the archive had already been downloaded and verified. The shipped properties restore `validateDistributionUrl=true` and use a 60-second network timeout. The distribution checksum remains mandatory. Neither the scripts nor the JAR were fabricated or downloaded separately.

Generated `gradle-wrapper.jar` SHA-256:

```text
2db75c40782f5e8ba1fc278a5574bab070adccb2d21ca5a6e5ed840888448046
```

All four Wrapper files are copied to every generated Android project. The generator sets executable permissions on the Unix script, and `.gitattributes` preserves platform-appropriate line endings. The CLI uses the local `gradlew.bat` on Windows or `gradlew` elsewhere. Downloads and caches use the standard Gradle user home (or the developer's `GRADLE_USER_HOME`). A failed download is reported without substituting versions or falling back to global Gradle.
